# Cheat sheet

Everything you can do with the mouse and keyboard, on one page.

## Knobs

| Do this | To get this |
|---|---|
| Drag up or down | Turn the knob |
| Shift + drag | Fine steps |
| Scroll over it | Turn in small steps |
| **Double-click** or **Option-click** | Back to its default (TUNE back to 0, PAN back to centre) |
| Click the **tempo** knob | Type a tempo, decimals allowed (92.5) |
| Option-click the tempo knob | Back to 120 |

While a step is held (red outline), a double-click or Option-click on a knob removes that step's
own setting for it.

## Everywhere

| Key | What it does |
|---|---|
| `Space` | Play / stop (starts the audio if it is off) |
| Click a module | It gets the keyboard; its name is underlined |
| `[` `]` | Previous / next module |
| `C` | Cables: show, dim, hide |
| Right-click **●** | Choose or open the recordings folder |

## Knockbox and Forge

| Do this | To get this |
|---|---|
| Click a step | Place or remove a note for the selected track |
| Right-click or Shift-click a step | Hold it: knobs now change that step only. Again, or `Esc`, to let go |
| `1`–`8` | Select a track and hear it |
| `A W S E D F T G Y H U J K O L P` | Play the selected track like a piano |
| `Z` `X` | Octave down / up |
| `R` | Live record what you play into the pattern |
| `←` `→` | Previous / next page of steps |
| Shift + CLEAR | Clear the whole pattern, not just the track |
| Click the **sound's name** (Knockbox) | Open the sound browser |
| Arrows on the sound's name | Step through the sounds in the same pack |
| Drop an audio file on Knockbox | Load it onto the selected track |
| Right-click the module | Rename or delete its sample, link pattern changes |

## Wander

| Do this | To get this |
|---|---|
| `A W S E D F T G Y H U J K O L P` | Play |
| `Z` `X` | Octave down / up |
| Click the **sample's name** | Open the sound browser |

## Reel

| Key | What it does |
|---|---|
| `1`–`4` | Select a track |
| `R` | Record |

## Cables

| Do this | To get this |
|---|---|
| Drag from one jack to another | Patch them |
| Drag a cable's end off an input | Unplug it |
| Right-click a jack | Clear everything plugged into it |

## Sound browser

| Do this | To get this |
|---|---|
| Click a pack | See its sounds |
| Type in the search box | Search every pack at once |
| Click a sound | Hear it on the track |
| Double-click a sound, or *Use* | Keep it |
| *Cancel* | Put the old sound back |
| *Add Pack…* | Copy a folder of sounds in as a pack |
