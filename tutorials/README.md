# Tutorials

Short walk-throughs, each about ten minutes. Start the app with `synth-rack` and load the
factory rack *First Light* (it is what opens the first time).

1. [Your first ten minutes](01-first-ten-minutes.md): play, pick a module, play the keys, record a take.
2. [Patterns and per-step changes](02-patterns-and-steps.md): placing notes, the red outline, giving one step its own pitch or sound.
3. [Playing samples in pitch](03-playing-samples-in-pitch.md): four ways to turn one sample into a melody or chords.

Two things that apply everywhere:

- **The keyboard plays whichever module you clicked last.** Its name is underlined.
- **Hover over any pad or jack** for a one-line description. Hover over a knob to see its value.
